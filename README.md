# 🌲 SylvaSense

AI-powered forest monitoring and analysis platform using satellite data to monitor forest ecosystems, analyze tree canopies, estimate biomass and carbon metrics, and detect deforestation over time.

## 🎯 Project Goal

SylvaSense aims to combine multispectral optical and Synthetic Aperture Radar (SAR) satellite data to provide detailed forest monitoring and support data-driven conservation.

## 🚀 Key Features

- 🛰️ Multispectral optical + SAR data fusion
- 🌳 Tree canopy segmentation and counting
- 🌱 Aboveground biomass estimation
- 🌍 Carbon metric forecasting
- 🚨 Deforestation detection and alerting
- 🗺️ Interactive forest monitoring map
- 📊 Temporal canopy degradation heatmaps
- 📍 GeoJSON boundary export
- 🔍 Live raster inference on selected forest areas
